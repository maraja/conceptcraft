# conceptcraft gotchas

Every row cost real debugging or a round of the format owner's feedback
during the reference builds. Check here FIRST when something renders wrong.

| Symptom | Cause | Fix |
|---|---|---|
| Self-drawing path renders as broken fragments | `vector-effect: non-scaling-stroke` inherited by **mask** paths breaks `pathLength` dash normalisation in Chromium | `.stage-sheet mask path, .stage-sheet mask circle { vector-effect: none; }` |
| Short segment fully drawn before its window | `stroke-linecap: round` on the mask paints a cap-dot at the dash boundary | `stroke-linecap: butt` on the drawmask |
| Every frame past the first is blank when embedded | An ancestor `overflow: hidden` creates a scroll container and kills `position: sticky` | Class-scoped `overflow: visible` on the main wrapper |
| Console sprays `<text> attribute x: Expected length "Infinity"/"NaN"` | render() ran against a zero-size viewport (hidden pane, pre-layout frame) | Guard: return early when `innerWidth/innerHeight < 2` or `!isFinite(ppu)` |
| In-app browser screenshots come back blank/stale while DOM probes look perfect | The app's browser pane is hidden; the compositor serves dead frames | Verify with the headless harness (shoot.mjs), not the pane |
| All the sheet text is squint-small | Counter-scaled `fs` is a LITERAL screen pixel size at every zoom | Floors: names 15, taglines 12, internals 11.5; olive halo on all sheet text |
| Code panels have a phantom blank line between every line | `.ln` spans are blocks AND the raw newlines between them render under `white-space: pre` | `code { white-space: normal }` + `.ln { white-space: pre }` |
| ANY authored ppu threshold fires on the wrong screens | ppu depends on viewport ASPECT, and the ranges overlap: a phone's stop framing can sit BETWEEN the 900-tall and 810-tall values of a wide framing, so no ppu value separates "desktop wide" from "phone" | Verify every threshold at 810 and 900 tall AND at 390x844; when the ranges overlap, key that gate off viewport WIDTH instead of ppu |
| A cluster is visible when it should be hidden, or vice versa, intermittently | Two owners writing the same element's opacity (`lods` in rescale vs the focus pass in render) | One owner per element: focus-driven elements never go into `lods`; they gate on `detail` inside render() |
| Overlapping platforms create a double-dark patch | Two translucent rects stacking | All plates in one `<g class="e-plates">` with group opacity and solid child fills |
| Station name runs through its own diagram | Radial label-placement formula | Author `{lx, ly, la, pAbove}` per stop into its empty quadrant |
| Neighbor stops still "block" the focused one | Dimming instead of two states | Rest = sage mark + grey name + NO internals/plate; only the subject expands (focus trapezoids) |
| Long internals label pokes past its platform | Screen-px label ÷ ppu is world width; plates sized to glyphs only | Size plates for labels too; widen when relabeling |
| Title/breath/colophon copy fights the grid and frame lines | Bare text on the sheet (the breath card ships bare in the reference and fails over a busy full-sheet framing: measured 1.9:1 once) | Gradient scrim behind `card--bare` copy; SOLID background on mobile (long headlines escape gradients — this failed contrast at 2.3:1 once) |
| Mast runs under the HUD on phones | Both fixed at top | `mast { max-width: calc(100vw - 12.5rem) }` on mobile |
| Harness reports dead scroll everywhere | It cannot see the bespoke camera, CSS-driven ink, or JS state playback; authored plateaus look dead | Probe live state (viewBox, token, counters, lit lines) across flagged windows; document false positives |
| Side-rail nav collides with cards at some point | Cards anchor to both bottom corners; any vertical rail shares a corner | Strip nav bottom-center on all sizes |
| `Day <!-- -->01`-style comment splits (if ported into React) | React separates static text and interpolations | One template literal |
| Cue stays lit while the act unpins | A non-final cue given one value | Every cue except the last closes with a two-value window |
| Port already in use | Any written list of taken ports is stale the day after it is written | Probe before binding (`lsof -ti :PORT` or just try and step up); record the port actually used in the FINGERPRINTS row |
| The 810-tall verification run silently ran at 900 | shoot.mjs's undocumented default desktop viewport is 1440x900 | Pass `--height 810` explicitly for the second run; and on a one-act page `--per-act N` is simply the total frame count |
| A multi-line counter-scaled text block smears into one blob on phones | Lines offset in WORLD units under screen-px type: at ppu ~0.2–0.6 the 12px glyphs outgrow the world leading | Gate the block on a ppu floor (~0.6), or space the lines with screen offsets ÷ ppu like rescale() does |
| Sheet labels refuse to column-align with spaces | SVG `<text>` collapses runs of spaces | Interpuncts (`·`) for gaps on sheet labels; only HTML panels can space-align (via `.ln` + `pre`) |
| Finale/plane labels pile into an unreadable heap on phones only | Fixed-screen-px labels over a world region that phone framings compress to ppu 0.2–0.3 | Gate dense label groups on ppu ≥ ~0.45; below it show the bare shapes and let the card carry the words |
| The breath card sits on top of a lit cluster | The breath's screen anchor coincides with whatever the camera frames near its window (a decision point at the ring's bottom vs a bottom-center card) | When sketching camera boxes, also pick the breath card's anchor to be disjoint from the cluster lit near p ≈ its window |
| The token parks on a name's letterforms at the resolution moment | Exit/arrival paths authored to end near a label line; the parked state is held for many frames | End token travel at a node CENTER (dock it inside the terminal ring), never at a path endpoint chosen for the drawn spur; nudge the label down for air |
| A moving dot vanishes at its most dramatic moment | It was recolored to match the element it sits on (a clay dot stalled ON a clay dashed edge is camouflage) | Keep the mover its identity color; put the verdict color in a swelling ring or halo around it |
| A key beat exists in code but never appears in any frame | The harness samples ~2% steps; a beat narrower than one step falls between frames | Give every load-bearing beat a hold of at least 0.02 of p, and confirm it lands in an actual frame |
| Copy edits silently violate the skin | — | No em dashes anywhere visible; clay never on small text; no danger color; keep your own wordmark styling consistent everywhere |
| The finale drifts on phones or in the harness | Time- or randomness-driven animation | Every frame is a pure function of scroll p; no Date.now(), no Math.random() |
| Three of four verification runs silently used the wrong viewport | The four shoot.mjs commands were batched through a shell loop over a variable; zsh does not word-split unquoted expansions, so the whole string became one `--out` value | Run the four commands literally, one invocation each, and confirm viewport and frame count in each report before believing it |
| Cannot frame a specific stop or beat to screenshot it | `report.json` indexes by document percent and scroll y, never by act progress | `scripts/probe.mjs <outdir> <w> <h> p1 p2 ...` shoots at exact act-progress values |
| Sheet labels are never contrast-checked | The harness measures HTML cue text only; the sheet is SVG | `scripts/svgcontrast.mjs` (+ `px.mjs`) measures on-screen contrast for SVG labels |
| `assemble.mjs`'s local-reference guard looks like it found leaks | The engine's own doc-comment contains `src="p1.webp"`, `leg1.mp4`, and `scrollcraft.js` | Those three grep hits in `artifact.html` are comments; the guard is correct |
| Small text on a PAPER panel fails contrast while the harness says everything clears | The harness measures cue text at the cue level and treats some small labels as large; dark-on-paper roles at alpha 0.55-0.62 land at 3.4-4.3:1 | On `#f2eee4` paper, ink `rgba(35,36,30,α)` needs **α ≥ 0.64** for 4.5:1 — use 0.70 for every caption, citation, table header, year stamp and legend. Clay accents on paper: `#8d5a36` (4.97:1) or darker; `#8a6a24` fails at 4.35:1, use `#7a5f1c` |
| A vendored helper script cannot find playwright-core | ESM resolves bare imports relative to the SCRIPT, not the cwd, and the skill directory has no node_modules | Copy `probe.mjs`/`svgcontrast.mjs`/`px.mjs` into the build's `lab/` before running them, and point their URL at the port you actually served |
| A caption silently rewrites a formula | `.card__cap` sets `text-transform: uppercase`, which turns `sigma'(z)` into `SIGMA'(Z)` and epsilon into E | Wrap symbol-bearing caption text in a `.nocase` span (`text-transform: none`). Any mode teaching math needs this |
| Plates paint over the drawing, not behind it | The plate group was created after the elements it sits under; the reference gets away with building plates late only because its plates never overlap the drawing | Hoist the plate group to just above the sheet ground, before everything it could cover — not merely "before the focus clusters" |
| A finale card fades out mid-run | The card's cue ramp-out starts before the run's last pass | A finale card's cue must outlast its run: end the cue after the last state change, not at it |
| A full-width topology collides with its own finale card | The card eats roughly 28% of the world width, so a drawing spanning the whole sheet cannot share a frame with it | Clear the card VERTICALLY: raise the finale camera box until the far end of the drawing sits above the card top, and check at 810 — it is the binding case, not 900 |
| `detail = ppu >= 1.45` fires on the wrong screens once one stop needs a wider box | No single ppu separates a wide stop framing at 900 from the same framing at 810 and the finale | Make the threshold per-stop (a `dmin` on each station) and gate the phone case on viewport WIDTH, not ppu |
| The vendored `probe.mjs` reports nothing useful in a new build | Its state block reads the PREVIOUS build's DOM ids (`hud-*`, `#todos`, `.t-center`) | Copy it to `lab/`, repoint the URL, and rewrite the state block for this build's ids — only the scroll-to-p mechanism is reusable |
| `svgcontrast.mjs` reports 1.00:1 for readable labels | It samples the SVG sheet and cannot see cards or the spotlight, so anything behind a card or recessed by the spotlight reads as a false failure | Treat its output as a candidate list: confirm each hit in the actual frame before fixing anything |
| A chalk/roughening filter shreds every stroke into sparkle | The filter's `scale` and `baseFrequency` are WORLD units, but sheet strokes use `vector-effect: non-scaling-stroke`, so at a stop framing a 2.4px wire is ~1.15 world units and a scale of 2.2 displaces ~96% of it | Drive both from ppu in `rescale()`: `scale = 1.3/ppu`, `baseFrequency = ppu/3.3`, keeping the grain constant in SCREEN px at every zoom |
| One perfectly horizontal or vertical element vanishes under a filter | A percentage filter region collapses on an axis-aligned element: its bbox height is 0, and 140% of 0 is 0 | Filter a GROUP (a group bbox is always 2D), not the individual straight edge. Circles and arcs are safe individually |
| Sheet labels silently change typeface mid-page | A handwriting face typically has no Greek, no combining marks, no interpunct and no arrows, so `sigma`, `yhat` and `·` fall back to a system cursive | Check the face's coverage before switching sheet labels to it; give symbol-bearing labels an opt-out class that stays mono. If the face is Regular-only, drop `font-weight: 700` or the browser synthesises a bold |
| The harness reports a contrast failure on a card that is plainly readable | It hides `[data-sc-cue] *` to sample the ground, which also hides a purely transparent card's wash, so it measures the DRAWING underneath | Declare the card's ground colour explicitly (`background: var(--sc-canvas)`) rather than leaving it transparent: same pixels, but the harness takes the own-fill branch and measures correctly |
| Removing the HUD's border opens a gap you never knew it was filling | A panel border was doing separation work between mast and HUD on phones | After dropping chrome fills, re-check the phone framings for elements that were only separated by a border |
| Grey specks appear along a drawn path on a LIGHT ground | Every masked draw-on path at `stroke-dashoffset: 1` still paints a sub-pixel sliver at the path's seam; on dark olive it is invisible, on paper it reads as dirt | Gate each masked path's opacity on its own `f0` in render() so it is genuinely absent before its window |
| Sheet labels look thin and under-contrast on paper despite correct colours | The paint-order halo is sized for dark grounds; at 0.32em a light halo eats the stems of 11-12px mono labels | Narrow the halo to ~0.26em on light worlds; it cost a full contrast point on one build |
